# Movie Library

**Автор:** Ковригин Илья

## Описание
Простое GUI-приложение для хранения информации о фильмах с возможностью фильтрации по жанру и году выпуска. Все данные сохраняются в файл JSON, а для контроля версий используется Git.

## Возможности
- Добавление фильма с проверками введённых данных
- Просмотр списка фильмов
- Фильтрация по жанру и году
- Сохранение и загрузка данных через JSON
- Использование Git для управления проектом

## Запуск
1. Клонируйте репозиторий
2. Установите Python (поддерживаются версии 3.x)
3. Запустите файл `movie_library.py`

## Пример теста
- Добавьте фильм: Название: "Inception", Жанр: "Sci-Fi", Год: 2010, Рейтинг: 8.5
- Проверьте отображение в таблице
- Попробуйте применить фильтр по жанру "Sci-Fi" или году "2010"
